# 🍕 Pizza Shop Billing System (Python Mini Project)

## 📌 Project Title
**Pizza Shop Billing System Using Python**

---

## 📝 Abstract
This mini project is a simple **Pizza Shop Billing System** developed using **Python**.  
It allows users to:
- View the pizza menu  
- Select a pizza  
- Enter quantity  
- Calculate the total bill  

The project uses **functions** and **dictionary data structure**, making it beginner-friendly and easy to understand.

---

## 🎯 Objectives
- To create a simple billing system using Python  
- To use dictionary for storing menu details  
- To apply functions for modular programming  
- To calculate total bill based on user input  

---

## 💻 System Requirements

### Hardware
- Computer / Laptop  

### Software
- Python 3.x  
- Any Python IDE (IDLE / VS Code / PyCharm)

---

## 🛠 Tools & Technologies Used
- **Programming Language:** Python  
- **Concepts:**  
  - Dictionary  
  - Functions  
  - Conditional Statements  
  - User Input  

---

## ⚙️ Algorithm
1. Start  
2. Display menu options  
3. User selects menu or order  
4. Take pizza number and quantity  
5. Calculate total bill  
6. Display the total amount  
7. Stop  

---

## 🧩 Project Description
The pizza menu is stored using a **dictionary**, where:
- Key → Pizza ID  
- Value → Pizza Name and Price  

Functions are used to:
- Display menu  
- Take user order  
- Calculate and display the bill  

---

## ✅ Advantages
- Easy to use  
- Beginner friendly  
- Reduces manual calculation errors  
- Simple and modular code  

---

## ❌ Limitations
- Supports only single order  
- No database connectivity  
- No GST or discount calculation

## 🚀 Future Enhancements

This **Pizza Shop Billing System** project successfully demonstrates the use of Python basics such as **functions**, **dictionaries**, and **conditional logic**.
